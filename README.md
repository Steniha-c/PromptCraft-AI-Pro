# 🚀 PromptCraft AI

PromptCraft AI is a Prompt Engineering Playground built using **Python, Flask, and Streamlit**.

It helps users understand and practice modern prompt engineering techniques by creating, evaluating, and improving AI prompts.

---

# Features

## ✅ Prompt Builder

Create structured prompts using:

- Role
- Task
- Output Format
- Few-shot Examples
- Chain-of-Thought

---

## ✅ Prompt Evaluation

Automatically checks whether your prompt contains:

- Role
- Task
- Output Format
- Examples
- Chain-of-Thought

and gives a score out of **100**.

---

## ✅ Few-shot Prompting

Generate prompts using multiple examples before asking the actual question.

---

## ✅ Self-Consistency

Demonstrates multiple reasoning paths before selecting the most consistent answer.

# Installation

Clone the repository

```bash
git clone https://github.com/yourusername/PromptCraftAI.git
```

Move into the folder

```bash
cd PromptCraftAI
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

# Run Flask

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```

---

# Run Streamlit

```bash
streamlit run streamlit_app.py
```
